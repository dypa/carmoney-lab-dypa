# Порядок работы

1. Получить JSON от пользователя в чате.
2. Спросить путь к файлу; по умолчанию предложить `backend/src/Dto/`.
3. Спросить имя класса DTO (если не следует из JSON), вывести namespace `CarMoneyLab\Dto`.
4. Распарсить JSON, составить список полей по образцу.
5. Сгенерировать файл и показать содержимое.

# Формат результата

- Один PHP-файл, `declare(strict_types=1)`, `final class`, namespace `CarMoneyLab\Dto`.
- Свойства — через конструктор, `private readonly`.
- Имя файла = имя класса + `.php`.
- Показать полный файл в одном блоке кода.

# Чек-лист

- [ ] Все поля из JSON присутствуют, ни одно не пропущено.
- [ ] Типы и null-обработка соответствуют JSON.
- [ ] `declare(strict_types=1)` в начале.
- [ ] Класс `final`, свойства `private readonly`.
- [ ] Namespace `CarMoneyLab\Dto`, PSR-4 путь `backend/src/Dto/`.
- [ ] Путь к файлу задан пользователем или принят `backend/src/Dto/`.
